First Official Devlog!

10/10/26

Well, it has somehow been a month since I last updated this site. I've really been having a lot of fun coding with Java for the past month. Prior to this month, Java is a language that I had never used before. As I experimented and played with it more and more, the more I fell in love with the syntax and how it works. My goal is to make some kind of epic questing game. I've had this idea for years. If I recall correctly, my first idea for this game started during my sophomore year of high school.

The first system I decided to work on is a simple time managment system, similar to Minecraft or Stardew Valley. I did take the Stardew route of going in 10 minute increments, but that is subject to change as I work more and more on the project. I am using LibGDX for this project, but in this specific instance I opened a separate Java file just to see what I could do with base Java, and I'm pretty proud! At the bottom of this post, you'll see an attached screenshot of what it looks like... although it is really just some text in my VS Code console. As much as I love using Java and learning it, I am hoping that I will be able to make a final version of this game in C# using Monogame. I feel this way mainly because if this game manages to reach any level of success and I want to port it to a console, then I'd need to have it all recoded for a proper console port. Although something like that is unlikely, I still would rather have my game future proofed.

Thanks for reading this week's post. Hopefully all my grammar is correct. (Also, let's hope that I get more posts out this month)

- Polar Moon

Welcome to Polarmoon.net

9/10/26

This is a devlog where I will attempt to document my progress on multiple games that I will be developing. I don't really like engines like Unity, Unreal or Godot. Unity just doesn't feel right to me when using it, and I really don't like writing GDScript... It feels like a worse Python/Lua/JavaScript. To be honest, I've never used Unreal before, but I also don't make super graphically intense games that would be suited better for Unreal. I will mostly use the following:

  • LOVE2D
  • Monogame
  • Pygame
  • LibGDX
  • Raylib for C++ (maybe)

I'll keep this devlog site updated as I progress. Sometime within the next week or two, I'm hoping to begin a small "learning" project in LibGDX. I haven't ever used Java, but would like to learn. That wraps up my thoughts for today. Thanks for reading!
